# Original procedural sound library

SPDX-License-Identifier: CC0-1.0

These WAVs are generated by `scripts/build_sound_library.py` using deterministic
mathematical synthesis. They contain no downloaded samples or third-party songs.
The original generated sounds are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

`library.json` records each sound's source and license. The four-note music bed
and stylized ambience are intentionally simple; they are not a claim of a
professionally recorded/composed soundtrack. Foley only plays for directed
actions; quiet ambient beds duck under approved speech.
